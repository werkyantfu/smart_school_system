# Coding Standards
## Smart SMS Project

All developers must follow these rules to keep the code clean.

## 1. Backend (PHP / Laravel)
- **Classes:** Use PascalCase (e.g., `StudentController`).
- **Methods:** Use camelCase (e.g., `getStudentById`).
- **Database Tables:** Use plural snake_case (e.g., `students`, `invoices`).

## 2. Frontend (Vue.js)
- **Components:** Use PascalCase (e.g., `StudentForm.vue`).
- **Script Setup:** Always use `<script setup>`.

## 3. Git Commit Messages
- `feat: add student registration form`
- `fix: correct fee calculation logic`
- `docs: update installation guide`

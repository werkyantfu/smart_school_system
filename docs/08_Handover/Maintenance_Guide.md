# Maintenance Guide
## Smart SMS Project

This guide helps the IT team maintain the system after launch.

## 1. Regular Updates
- Run `git pull` to get the latest code updates.
- Run `composer update` and `npm install` to update libraries (do this carefully in a staging environment first).

## 2. Monitoring Logs
Check for errors in the Laravel log file:
`storage/logs/laravel.log`
